## Analysis
For my benchmarking I tested convetional matrix multiplication, pure Strassen, and hybrid Strassen with different cutoff sizes. 

Conventional was faster for smaller matrices due to not having to recursively split, but the hybrid algorithm which switched to conventional math, was better for larger matrices. From my results, it appears a cutoff of 32 performed best overall.
